DECODERS' MANUAL • TOP SECRET

Mainframe Decryption Guide

Ask your Hacker what is on their screen. Read rules top-to-bottom and stop at the first rule that matches!

MODULE 1: SERVER WIRES

Ask for the 5 wire colors (top to bottom) and the Serial Number. Follow the FIRST matching rule:

  1. If there are NO RED wires → Cut the 2nd wire.
  2. Else if the last (5th) wire is WHITE → Cut the 4th wire.
  3. Else if there is more than one BLUE wire AND the Serial ends in an ODD digit (1,3,5,7,9) → Cut the LAST BLUE wire.
  4. Else if there is exactly ONE YELLOW wire → Cut the 1st wire.
  5. Otherwise → Cut the 3rd wire.

MODULE 2: THE OVERRIDE BUTTON

Ask for the button's COLOR and WORD. Follow the FIRST matching rule:

  1. If the button is RED and says "HOLD" → TAP ONCE.
  2. Else if the button says "DETONATE" → DOUBLE-TAP quickly.
  3. Else if the button is BLUE or YELLOW → HOLD for 3 seconds.
  4. Otherwise → TAP ONCE.
